# Рабочее место специалиста (демонстрация)

Экран показывает открытые синтетические обращения, рекомендованную категорию и похожие закрытые заявки. Специалист редактирует черновик и сохраняет решение «согласовать» или «отклонить». После отклонения локальная языковая модель переписывает ответ по свободному замечанию специалиста. Ответ заявителю автоматически не отправляется.

После обучения поиск использует небольшую полносвязную нейронную сеть. Она получает символьные признаки темы и учится различать 15 типов синтетических проблем. Скрытый слой сети служит представлением текста для сортировки закрытых заявок. При отсутствии обученной модели остаётся поиск по совпадению слов. Оценка сходства не является вероятностью правильного решения. Тексты решений в имитаторе синтетические и шаблонные.

После полной загрузки данных соберите контейнер командой `docker compose --profile operator build operator` и обучите поисковую сеть командой `docker compose --profile operator run --rm operator python train_neural.py`. Запустите сервисы командой `docker compose --profile operator up -d --build operator reply-model`, затем один раз загрузите языковую модель командой `docker compose --profile operator exec reply-model ollama pull qwen2.5:3b`. Откройте `http://localhost:8502`. При первом запросе переработка ответа может занять заметное время. Языковая модель работает локально и хранится в томе Docker. Для подключения к базе нужны переменные `POSTGRES_HOST`, `POSTGRES_PORT`, `POSTGRES_DB`, `POSTGRES_USER`, `POSTGRES_PASSWORD`. Веса поисковой сети сохраняются в `artifacts/neural_model` и не попадают в Git.

Обучение использует 15 различных тем закрытых заявок и синтетические перефразировки. Разные формулировки одной темы разделены между обучением, выбором эпохи и итоговой проверкой. На 15 ранее не виденных формулировках поиск сетью поставил правильный тип первым в 11 случаях, поиск по словам — в 7. В каждом случае сравнивались три типа одного сервиса. Эти числа не характеризуют работу с реальными обращениями.

Результат проверки сохраняется в таблице `demo.reply_reviews`. Согласованные ответы также используются моделью подбора примеров. Локальная языковая модель уже обучена до установки и не дообучается на каждом замечании: она применяет свободное замечание к текущему черновику. Если она недоступна, экран показывает предупреждение и оставляет ручное редактирование. В журнал событий записываются только номера заявок, действия и виды ошибок, без текстов обращений и реквизитов базы.
